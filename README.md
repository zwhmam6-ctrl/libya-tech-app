# تقنية ليبية — مساعدك الذكي 🇱🇾

نسخة محسّنة بواجهة تشبه ChatGPT: قائمة محادثات جانبية، محادثات متعددة محفوظة، تصميم مميز.

## هذه نسخة محدّثة — كيف تستبدل الملفات القديمة

1. أوقف السيرفر القديم إن كان شغالاً (Ctrl+C بـ PowerShell)
2. احذف مجلد `static` القديم بمشروعك، واستبدله بمجلد `static` من هذا الملف
3. ملف `main.py` نفسه (لم يتغيّر) — تقدر تستخدم القديم أو الجديد، هما متطابقان
4. **مهم**: انسخ ملف `.env` القديم (فيه مفتاحك) إلى المجلد الجديد، أو انسخ محتواه لملف `.env` جديد

## خطوات التشغيل من الصفر (لو نسخة جديدة كاملة)

```powershell
cd مسار-المجلد
py -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

أعد تسمية `.env.example` إلى `.env` وضع مفتاحك فيه:
```
OPENROUTER_API_KEY=sk-or-v1-مفتاحك
```

شغّل:
```powershell
uvicorn main:app --reload
```

افتح: `http://127.0.0.1:8000`

## المميزات الجديدة

- قائمة محادثات جانبية (Sidebar) قابلة للطي
- حفظ عدة محادثات تلقائياً بالمتصفح (localStorage)
- إمكانية حذف أي محادثة
- بطاقات اقتراحات بالشاشة الرئيسية
- تصميم متجاوب يعمل على الجوال
- مؤشر "يكتب..." متحرك أثناء انتظار الرد
